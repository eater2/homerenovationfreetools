Privacy Policy

Last updated 2026-10-19

This policy covers the website at home-renovation-free-tools.vercel.app, the MCP server at /mcp (also published on npm as home-renovation-free-tools) and the Claude plugin and skill of the same name.

What we collect

  • No accounts, sign-in, cookies, analytics or ads.
  • The MCP server answers searches over a public list of tools. It does not store your search text or any conversation content.
  • For usage counts, the hosted MCP server writes one log line per request with the method, tool name and category filter only, never the query text. These logs are kept by our host, Vercel, for its standard retention period.
  • Like any web host, Vercel processes technical request data (such as IP address and user agent) to serve and protect the site. See Vercel's privacy policy.

The npm package and the plugin

The npm package runs on your own machine and only downloads the public list (catalog.json) from GitHub. The Claude plugin is a skill that reads the same public files. Neither sends your data anywhere.

Third-party tools in the list

The list links to external websites and apps. When you open them, their own privacy policies apply.
